# Valentte email conventions

## Standard links (Bloomreach emails)

Use these destinations in every Valentte marketing email, new or edited:

| Element | URL |
|---|---|
| "Home Fragrance" link in the top nav | https://valentte.com/about-home-fragrance/ |
| "Refills" tile/link (e.g. "You May Also Like" row: image + text link) | https://valentte.com/home-fragrance/natural-reed-diffuser-refills/ |

Do not use the old destinations:
- `https://valentte.com/home-fragrance/` for the nav "Home Fragrance" link
- `https://valentte.com/refills/` for Refills

When building or editing an email, check every Home Fragrance and Refills link (image wrapper and text link both) against this table before saving.
